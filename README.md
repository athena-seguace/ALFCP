# Analysis of Lissajous Figures in a Coupled Pendulum System

This is a student-made experimental setup for the General Properties of Matter Laboratory, Department of Physics, IIT Kharagpur.


It was prepared as a simple demonstration for future lab use.
The system models a coupled pendulum and stores its data. The client sends this data to a server, which runs a C++ program and generates a dataset of the “dot” motion forming Lissajous figures. The client can then load any generated dataset and visualize the trajectory as an animation.
